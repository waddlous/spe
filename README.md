
# Simple Physics Engine: spe

## Features: (most of which are yet to be added)

Physics simulation including mass, velocity, gravity etc.  
Perspective view for a 3-dimensional space  
Simple CLI  
Save the current state of the engine to files  
Load engine states from files  
Detailed object data log  

## Platforms:

Runs natively on linux  
Will add windows support  
(which is why the batch file is there)  
Not considering to add OSX support
